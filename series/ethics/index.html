Reading 05: Why we should not lose points for segfaults

Written Feb 18, 2018 - Projects

The Therac-25 accidents were caused by reliance on software for safety-critical function, and that software not being absolutely perfect. Software designers have to be incredibly careful to ensure that every state the system can be in is a safe one, or at least, if it is ever in an unsafe state, alert any operator very clearly. The Therac-25 incidents were caused by this not being followed - if a user switched modes too quickly, the machine would be left in an unsafe state.
